Công cụ Import Lịch tự động

Chọn file Excel, tải CSV và mở nhanh trang Google Calendar

📂 Kéo thả file Excel hoặc Click để chọn
⚡ Quy trình sau khi bấm nút màu xanh:
  1. File calendar_import.csv sẽ tự tải về máy.
  2. Trang Google Calendar Import sẽ tự động bật ra ở tab mới.
  3. Bạn chỉ cần kéo file vừa tải vào ô "Chọn tệp từ máy tính" và ấn Nhập (Import).
