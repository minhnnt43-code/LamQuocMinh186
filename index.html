      📝 Ghi nhanh (TodoList)

      • Cuộn xuống phần "Ghi nhanh" để tạo nhóm
      • Gõ tên việc + shortcut ngày: /hn hôm nay, /mn ngày mai, /T6 Thứ 6, /25-3 ngày cụ thể
      • Bấm 📋 để chuyển thành Công việc chính thức

      📊 Nhập hàng loạt (Excel)

      • Bấm nút "Excel" ở thanh công cụ
      • Gõ trực tiếp vào bảng — không cần tải file
      • Dữ liệu tự động lưu nháp — đóng mở vẫn còn
      • Bấm "✅ Nhập tất cả" để tạo công việc

      📅 Đồng bộ Lịch

      • Tạo task có ngày hạn → tự hiện trên Calendar
      • Sửa event trên Calendar → task tự cập nhật
      • Xóa task → event bị xóa theo
      • Màu event theo mức ưu tiên: 🔴🟡🟢

      👁️ Chế độ xem

      • Danh sách — xem dạng bảng
      • Gantt — biểu đồ tiến độ
      • Thống kê — phân tích hiệu suất
